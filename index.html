🔒 Privacy Policy & Security Architecture

1. Client-Side Only Storage

This Progressive Web App stores student academic profiles, grades, and preferences exclusively inside your local browser storage (localStorage & IndexedDB). There is no central user database or tracking server.

2. AES-GCM-256 Cryptographic Vault

Stored credentials are encrypted using the native browser Web Cryptography API (window.crypto.subtle) with 100,000 rounds of PBKDF2 key stretching. Passwords never touch disk unencrypted. If an optional Security PIN is set, the PIN is never saved to disk and must be provided in-memory during sync.

3. Stateless Edge Sync Relay

The 1-Click Fast Sync relay operates in 100% pass-through stateless mode solely to bridge browser cross-origin restrictions (CORS). The relay does not persist, log, or track passwords, usernames, or academic grades.

4. Disclaimer of Affiliation

This application is developed independently by engineering students for educational and academic tracking purposes. It is not affiliated with, endorsed by, or representing APJ Abdul Kalam Technological University. Official results and regulations can be verified on app.ktu.edu.in.
